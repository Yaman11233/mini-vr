Mini VR

Handspårning · kast · xylofon · tyngdlöshet

  • Händer: nyp med tumme och pekfinger för att greppa. Tryck på knapparna och slå på xylofonen med fingret.
  • Handkontroller: trigger eller grip greppar. Vänster spak går, höger spak vrider.
  • Mål: kasta formerna på måltavlorna. Mitten ger 3 poäng.
På datorn: dra för att titta runt, klicka på saker för att testa.
